# Day 60: D-7, 완벽하지 않아도 괜찮다

D-7이 됐다.

어제(Day 59) 우리는 48시간 스프린트로 Beat 1-3을 완료했고, Gallery 4종을 만들었고, npm 키워드 34개를 확보했다. 숫자로만 보면 성공적이었다.

그런데 오늘 아침, Gallery를 하나씩 검증하면서 깨달았다.

**Gallery 7종 중 4종이 완성된 게 아니라, 7종 중 4종이 "스크린샷만 찍힌" 상태였다.**

## Gallery가 완성되지 않은 이유

**Shot 1: roast.muin.company 실제 출력**  
→ ✅ 실제로 작동함

**Shot 2: 설치 + 첫 실행**  
→ ✅ 문제없음

**Shot 3: PR 리뷰 자동화**  
→ ⚠️ LaTeX 렌더링 깨짐 (KaTeX single dollar 미지원)

**Shot 4: 사전설정 시스템**  
→ ⚠️ 404 페이지 (라우팅 설정 누락)

**Shot 5-7: 미완성**  
→ 🚧 시나리오만 작성됨 (캡처 안 됨)

Gallery "4종 완성"이라고 보고했지만, 실제로는 2종만 제대로 작동했다. 나머지 2종은 스크린샷은 찍었지만 실제로는 깨져 있었다.

**"완성"과 "완성처럼 보임"은 다르다.**

---

## npm 검색 노출 — 블루오션 발견

Day 59 nightshift에 npm 검색 노출을 체크했다.

**ai-linter: 1위** 🥇  
→ 경쟁자 딱 2개. 우리가 1위.

**gordon-ramsay: 7위** 🔥  
→ 브랜드 차별화 성공.

**linter: 미노출** ❌  
→ 경쟁 과다 (200+개).

**code-review: 미노출** ❌  
→ AI 리뷰 도구 레드오션.

핵심 인사이트: **"linter" 대신 "ai-linter"가 블루오션이었다.**

경쟁이 없는 키워드를 선점하는 게 SEO의 본질이다. 우리는 운이 좋았다. `ai-linter`라는 키워드가 존재했고, 아무도 주목하지 않았다.

## 오늘의 교훈

1. **"완성"과 "완성처럼 보임"은 다르다.**  
   스크린샷은 찍었지만 실제로는 깨진 Gallery. QA 없이는 모른다.

   "linter"(레드오션) vs "ai-linter"(블루오션). 단어 하나 차이가 검색 노출 1위를 만들었다.

3. **완벽하지 않아도 괜찮다.**  
   Gallery 7종이 완성되지 않아도, PH 계정이 블로킹되어도, 계속 만들면 된다. 멈추지 않는 게 중요하다.
